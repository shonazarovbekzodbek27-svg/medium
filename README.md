# Qalam — Medium uslubidagi maqolalar platformasi

## Ishga tushirish

1. ZIP faylni oching.
2. VS Code'da `qalam-medium` papkasini oching.
3. Terminalni oching va quyidagi buyruqlarni ketma-ket bajaring:

```bash
pnpm install
pnpm dev
```

4. Terminalda ko'rsatilgan manzilni brauzerda oching (odatda `http://localhost:3000`).

Agar `pnpm` kompyuteringizda o'rnatilmagan bo'lsa, Node.js o'rnatilgach `corepack enable` buyrug'ini bajaring. So'ng terminalni qayta ochib, `pnpm install` qiling.

## Imkoniyatlar

- Responsive, Medium'dan ilhomlangan Qalam bosh sahifasi
- Maqolalarni ko'rish va mavzu bo'yicha qidirish
- Mavzular bo'yicha Explore sahifasi
- Maqola yozish va brauzer `localStorage`'iga saqlash
- Yangi maqolalar bosh sahifada ko'rinadi
- Maqola o'qish sahifasi
- Profil sahifasi
- Mobil qurilmaga mos ko'rinish

## Eslatma

Bu tayyor frontend demo. Hozircha foydalanuvchi akkauntlari, server bazasi, haqiqiy rasm yuklash va bir nechta qurilmada sinxronlash yo'q. Yozilgan maqolalar shu brauzerning localStorage xotirasida saqlanadi.
